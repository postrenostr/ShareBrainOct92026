name: Mobile 10words access
description: Mobile navigation requirement and the user's confirmed resolution.
---

10words should be accessible above More on mobile as well as desktop, without unlocking More.

**Why:** The user reported that 10words was missing above More in a mobile browser even though the published shared navigation contained the link. They subsequently confirmed that the mobile navigation adjustment fixed the issue.

**How to apply:** Preserve this placement when changing navigation. Verify mobile visibility and drawer behavior rather than treating link presence in the shared component or published bundle as proof that it is visible on a phone.
